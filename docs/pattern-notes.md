# パターン運用メモ

`apps/site`のパターンに関する共通文言と、本文の翻訳以外の日英差分をまとめる。

## 本文の翻訳以外の日英差分

### 料金の通貨・表記

金額は換算処理や`toLocaleString`で生成せず、各言語のソースに表示用の文字列で記述する。ドル価格は表示例として設定し、実際の為替相場には連動させない。

| 対象 | 日本語 | 英語 |
| --- | --- | --- |
| Pricing01・Pricing02 | 円表記。金額に桁区切りを入れ、単位は`円/月`・`円/年` | ドル表記。金額の先頭に`$`を付け、単位は`/mo`・`/yr` |
| Pricing03 | 円の金額と`円/月` | 日本語版と同じ円の金額と`JPY/month` |

具体的な金額は[Pricing01](../apps/site/src/pages/preview/patterns/pricing/pricing01/)、[Pricing02](../apps/site/src/pages/preview/patterns/pricing/pricing02/)、[Pricing03](../apps/site/src/pages/preview/patterns/pricing/pricing03/)の`index.astro`・`en.astro`を参照する。

### Pricing02の表示調整

カードの構造とスタイルは日本語版を基準に揃える。通貨単位の文字間隔だけは、日本語の`円/月`・`円/年`に`lts="xl"`を指定し、英語の`/mo`・`/yr`には指定しない。

## 共通ダミーテキスト

`apps/site`のパターンで使う日本語のダミー文言と対応する英語コピーを、カテゴリごとにまとめる。見出し・説明文・リンク文言を揃え、レイアウトの違いを比べやすくする。

### Feature

SaaSソフトウェア系とデザインスタジオ系の2テーマを用意する。Feature01/02/03の日英プレビューで使用する。

#### 使い方

- SaaSソフトウェア系は6項目を用意し、3項目・4項目のレイアウトでは先頭から使う。デザインスタジオ系は3項目で構成する。
- リンクを置く場合、文言は両テーマとも「詳しく見る」に統一する。
- Feature01はSaaS系の先頭4項目、Feature02はデザインスタジオ系、Feature03はSaaS系の全6項目を使う。

#### SaaSソフトウェア系

作成中のダミープロダクト画面に合わせ、プロジェクト管理サービス「DevFlow」を題材にする。

**メイン見出し**

次にやることが、すぐわかる

英語版:

See what to do next at a glance

Feature01/03で共通の文言を使う。改行位置はレイアウトに合わせる。

**導入文**

チームのタスクと現状を、一つの場所に。DevFlowが毎日のプロジェクト管理をすっきりまとめます。

英語版:

Your team’s tasks and status, all in one place. DevFlow keeps everyday project management simple and organized.

| 特徴の見出し | 説明文 |
| --- | --- |
| タスクをまとめて管理 | 担当者や期限を決めて、やることを整理。ボードや一覧で、次に取り組む仕事を確認できます。 |
| プロジェクトの進捗を把握 | 完了したタスクや残りの作業をひと目で確認。チームの状況を見ながら、計画を調整できます。 |
| チームの情報を共有 | ドキュメントや日々の更新をひとつの場所に。必要な情報を共有し、認識のずれを減らします。 |
| 予定をひと目で確認 | タスクの期限やスプリントの予定をカレンダーに集約。先の予定を見渡して、無理なく仕事を進められます。 |
| ファイルをひとつの場所に | 資料やデザインをプロジェクトごとに整理。必要なファイルがすぐに見つかり、探す手間を減らせます。 |
| 繰り返す作業を自動化 | 定期的なタスクの作成や担当者への通知を自動化。毎日の細かな作業を減らし、大切な仕事に集中できます。 |

#### デザインスタジオ系

ブランディング・Web制作・公開後の運用支援を扱う架空のWebデザインスタジオを題材にする。

**メイン見出し**

私たちにできること

英語版:

What We Can Do

**導入文**

ブランドの考え方から、Webサイトの制作・運用まで。対話を重ねながら、一貫したデザインで事業を支えます。

| 特徴の見出し | 説明文 |
| --- | --- |
| ブランドをかたちにする | 大切にしている想いや事業の強みを整理。言葉やロゴ、色を通して、そのブランドらしさをかたちにします。 |
| Webで魅力を伝える | 届けたい相手と伝えたい内容を整理。情報の構成から見た目まで、目的に合ったWebサイトをつくります。 |
| 公開後の成長を支える | 公開後の反応を確かめ、課題を整理。日々の更新から内容やデザインの見直しまで、継続して支えます。 |

英語版の見出しは、順に「Branding」「Web Design」「Maintenance」を使う。
