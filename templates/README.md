# テンプレートの保守

この文書は、言語別ページの方針と意図的な言語差分だけを扱う。テンプレの規約（`package.json`の`"private": true`など）と、追加・配信の手順は[CLIガイドの「テンプレ運用」](../docs/cli-guide.md#テンプレ運用)にある。

## 言語別ページの扱い

言語別ページは、基準言語の文章だけを置き換えた複製ではない。文字量・文字組み・文化的な見せ方に合わせて、要素構造やレイアウトを変えてよい。下記の差分を不整合とみなし、片方へ機械的に揃えない。

共通する機能や挙動まで別々に保つという意味ではない。共通部分を変更するときは両言語への影響を確認し、言語固有の差分だけを維持する。

## 意図的な言語差分

### `lp/astro/ryokan`

対象は日本語版の`src/pages/ryokan/index.astro`、英語版の`src/pages/en/ryokan/index.astro`、共有スタイルの`src/pages/ryokan/_style.css`。

| 対象 | 日本語版 | 英語版 |
| --- | --- | --- |
| 本文書体 | `Shippori Mincho B1`を基準にする | 欧文用の`Lora`を基準にする |
| 基準本文サイズ | 1000pxで16px、1400pxで17px | 800pxで16px、1400pxで18px |
| アクセント書体 | `Yuji Syuku`を使う | 欧文は`EB Garamond`、日本語の屋号は`Yuji Syuku`を使う |
| Heroのキャッチコピー | 縦組みにし、行ごとに開始位置をずらす | 横組みにし、縦組み用のずらしを適用しない |
| Heroの文字サイズ | `clamp(1.5rem, 1.2857rem + 0.9524vw, 2rem)`で、360pxから1200pxの間に24pxから32pxへ変化させる | `clamp(1.5rem, 1.1786rem + 1.4286vw, 2.25rem)`で、360pxから1200pxの間に24pxから36pxへ変化させる |
| Heroの文字間と行間 | 縦組みに合わせて広く取る | 欧文の横組みに合わせて日本語版より狭くする |
| Heroの配置と寸法 | コンテナ側で中央に配置する | コピー側で余白と最大寸法を持ち、長い欧文に合わせて配置する |
| 補助ラベル | 英語のEyebrowを表示する | 対応する日本語をソースに残し、`b--enEyebrow`で非表示にする |

Hero周辺の要素構造やLismのレイアウトpropsは、上記を実現するため一致しなくてよい。
