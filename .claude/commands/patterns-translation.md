# Patterns Translation Sync

`apps/site/src/pages/preview/patterns/{category}/{id}/` の `index.astro`（日本語）を正として `en.astro` へ翻訳同期する。
`apps/site/src/config/patterns.ts` の `description.en`（カテゴリと各アイテム）も同期対象。

`en.astro` は `/en/patterns/...` ページにソースコードとしてそのまま表示される。コメントも含めて英語読者向けの完成品として扱う。
`preview/page-layouts/` は `index.astro` を共用し英語版を持たないため対象外。


## 対象範囲

- `$ARGUMENTS` でカテゴリ指定あり: そのカテゴリのみ
- 未指定: `preview/patterns/` 配下の全カテゴリ


## 作業手順

### 1. ファイル一覧の取得と分類

各パターンディレクトリの `index.astro` と `en.astro` の有無を Glob で取得し、3つに分類する。

| 分類 | 条件 | アクション |
| --- | --- | --- |
| 新規 | `index.astro` のみある | テキスト部分を英訳して `en.astro` を作成 |
| 更新候補 | 両方ある | サブエージェントに渡し、差分があれば更新 |
| 孤立 | `en.astro` のみある | 削除対象として報告 |

更新候補の差分判定はコマンド側で行わない（メインが全ファイルを読むとコンテキストを圧迫する）。担当サブエージェントが読み比べ、差分がなければ「スキップ」として報告する。差分の概要が分かっている場合はサブエージェントに渡す。

### 2. 分類結果の報告

分類結果を報告し、実行の承認を得る。

```
## パターン翻訳同期プラン

### 新規作成（{n}件）
- {category}/{id}/

### 更新候補（{n}件）
- {category}/{id}/

### 削除（{n}件）
- {category}/{id}/en.astro（対応する index.astro なし）

実行してよろしいですか？
```

### 3. 翻訳の実行

承認後に行う。

1. 孤立した `en.astro` を削除する
2. 新規・更新候補をカテゴリ単位で1グループ10件前後にまとめ、`lism-docs-translator` を並列起動する。`feature/` や `section/` のような大きいカテゴリは単独または分割し、数件しかないカテゴリは隣接カテゴリと統合する。各サブエージェントに渡すもの:
   - 担当パターン一覧（カテゴリ/ID）と対象ファイルパス
   - 各パターンが「新規作成」か「更新候補」か
   - 差分の概要（分かる場合）
   - 後述「パターン翻訳の個別ルール」の全文（プロンプトに含める）
3. `patterns.ts` はメインエージェントが更新する。新規カテゴリ・新規パターンは `description.en` を追加し、`description.ja` が変わっていれば `description.en` も更新する。

### 4. 最終チェック（コマンド側で実施。サブエージェントには渡さない）

全サブエージェント完了後、リポジトリルートで実行する:

```bash
rg -n '[一-龥ぁ-んァ-ヶー々]' apps/site/src/pages/preview/patterns --glob 'en.astro'
```

コメントも英訳対象のため、コメント行を除外しない。残っていれば担当サブエージェントに差し戻し、ゼロ件になってから完了報告する。

### 5. 結果の報告

サブエージェントの結果をまとめて報告する。

```
## パターン翻訳同期結果

### 新規作成（{n}件）
- {category}/{id}/en.astro

### 更新（{n}件）
- {category}/{id}/en.astro — {変更概要}

### 削除（{n}件）
- {category}/{id}/en.astro — 削除済み

### スキップ（{n}件）

### patterns.ts
- 追加 {n}件 / 更新 {n}件

### 最終チェック
- 日本語残留: なし / {n}件を差し戻して解消
```


## パターン翻訳の個別ルール（サブエージェントへ渡す）

対象は `.astro` のため、エージェント定義の「MDX の翻訳ルール」（frontmatter・`/en/` リンク・import パス調整・DummyText）は適用しない。「最優先: 意味の正確性」「翻訳の品質基準」「用語対応表」「避けるべき直訳パターン」には従う。

### 基本方針

共通コピーと通貨・表記・スタイルの日英差分は[パターン運用メモ](../../docs/pattern-notes.md)に従う。以下の同一化ルールは、同文書で定めた言語差分を除く。

- コンポーネント構造・import・props・CSS クラス名は `index.astro` と同じにする
- `import './_style.css'` は `index.astro` にあるときだけ同じく書く（両言語で共有。無いパターンでは書かない）
- `DemoLayout` の `title`、URL、`alt=""` のような空の alt はそのまま維持する
- 英訳するのはテキスト（見出し・本文・ボタンラベル等）とコメント（`{/* ... */}`）。コメントはソースとして表示され、コピペして使う読者向けの説明になるため英訳する

### 更新候補の場合

1. 両方を読み、コンポーネント・import の追加・削除・変更、props（レスポンシブ値・スタイル props）の変更、日本語テキスト・コメントの変更を見る
2. 差分がなければ変更せず「スキップ」として報告する。英訳の文言だけが違う場合（日本語側が変わっていない場合）も更新不要
3. 差分がある箇所だけ `index.astro` に揃え、変わっていない箇所の既存英文はそのまま維持する

### テキストの翻訳方針

- 直訳ではなく自然な英語にする
- ダミーテキストは英語の自然なダミーテキストに置き換える
- `en.astro` に日本語文字（漢字・ひらがな・カタカナ）を残さない。日本語固有表現は次のように英語化する
  - 人名: ローマ字で名→姓の順（佐藤 美咲 → Misaki Sato）
  - 日付: 英語の日付形式（2020年1月1日 → January 1, 2020）
  - 肩書き・役職: 英語の一般的な役職名（代表取締役社長 → CEO、部長 → Director）
  - 住所: 英語のダミー住所に置き換える
  - 電話番号: そのままでよい
