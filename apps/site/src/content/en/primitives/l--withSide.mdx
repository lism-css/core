import { WithSide, Grid, Box, Frame, Stack } from 'lism-css/astro';
import { DummyText } from '@lism-css/ui/astro/DummyText';

`l--withSide` is a two-column class that, without relying on media queries or container queries, **automatically switches between a horizontal and vertical layout based on the main content width you want to keep**.


- Specify the width of the side content with `--sideW`, and specify the width you want to preserve as much as possible for the main content with `--mainW`.
- While the main content has enough space to maintain `--mainW`, the layout stays horizontal; once it drops below that threshold, it automatically switches to a vertical layout.

Use it for layouts such as "image and content" or "main area and sidebar".

## CSS

<SrcCode path="src/scss/primitives/layout/_withSide.scss" />

One child element must have `is--side`.

```pug
div.l--withSide
  div
  div.is--side
```


## Lism Component

### Import

<ImportPackage component="WithSide" />

### Props

| Prop | Output | Description |
|---|---|---|
| `sideW`| <PropBadge type="cssvar">`--sideW`</PropBadge> | Width of the side element |
| `mainW` | <PropBadge type="cssvar">`--mainW`</PropBadge> | Minimum width to maintain for the main element |


## Usage

Specify the side element's base width with `--sideW`; once the main element's width falls below the value set by `--mainW`, the layout automatically switches to a single column.

### Reversed order

Using the `-fxd:row-reverse` class (`flex-direction:row-reverse`) together allows you to reverse only the horizontal order.

:::check
This places the side element on the left when horizontal, and at the bottom when stacked vertically.
:::

<Preview>
  <PreviewTitle>Example</PreviewTitle>
  <PreviewArea resize p="20">
    <WithSide fxd="row-reverse" sideW="10rem" mainW="16rem" g="20">
      <Box>
        <DummyText />
      </Box>
      <Box isSide bgc="blue:20%">Side Content</Box>
    </WithSide>
  </PreviewArea>
  <PreviewCode slot="tab" label="JSX">

    ```jsx 'fxd="row-reverse"'
        </p>
      </Box>
      <Box isSide>Side Content</Box>
    </WithSide>
    ```
  </PreviewCode>
  <PreviewCode slot="tab" label="HTML">

### Layout with alternating media and text

`l--withSide` also works for layouts that show media and text side by side on wide screens and stacked on narrow screens.

Use this pattern when stacking multiple "media + text" pairs — the media alternates left/right horizontally and stays at the top consistently when stacked vertically.

## Building a similar layout with `Grid`

`WithSide` (`l--withSide`) is not dependent on breakpoints, but you can also build a similar layout using [`Grid`](/en/docs/primitives/l--grid) where the switch point is controlled by a breakpoint.

<Preview>
  <PreviewTitle>Building a WithSide-like layout using `Grid`</PreviewTitle>
  <PreviewArea resize p="20">
    <Grid gta={[`'.' 'side'`, `'. side'`]} gtc={[null, '1fr 10rem']} g="20">
      <Box>
        <DummyText />
      </Box>
      <Box ga="side" bgc="blue:20%">Side Content</Box>
    </Grid>
  </PreviewArea>
  <PreviewCode slot="tab" label="JSX">
    ```jsx "gta=" "gtc="
    <Grid gta={[`'.' 'side'`, `'. side'`]} gtc={[null, '1fr 10rem']} g="20">
      <Box>
        <p>
          Lorem ipsum dolor sit amet. Consectetur adipiscing elit, sed do eiusmod tempor Incididunt ut. Labore et dolore magna aliqua. Ut enim ad minim
          veniam, quis nostrud exercitation ullamco laboris nisi ut.
        </p>
      </Box>
      <Box ga="side">Side Content</Box>
    </Grid>
    ```
  </PreviewCode>
  <PreviewCode slot="tab" label="HTML">
    ```html "-gta -gta_sm -gtc_sm" "'. side' / 1fr 10rem" "-ga" "--ga:side"
    <div class="l--grid -gta -gta_sm -gtc_sm -g:20" style="--gta: '.' 'side'; --gta_sm: '. side'; --gtc_sm: 1fr 10rem">
      <div class="l--box">
        <p>Lorem ipsum dolor sit amet. Consectetur adipiscing elit, sed do eiusmod tempor Incididunt ut. Labore et dolore magna aliqua. Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris nisi ut.</p>
      </div>
      <div class="l--box -ga" style="--ga: side">Side Content</div>
    </div>
    ```
  </PreviewCode>
</Preview>
