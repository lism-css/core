import { Lism, Box, Frame, Media, Columns, Grid, Divider, Heading, Text } from 'lism-css/astro';
import { DummyText } from '@lism-css/ui/astro/DummyText';

`l--columns` is a column class that **displays content in the specified number of columns at each breakpoint**.

## CSS

<SrcCode path="src/scss/primitives/layout/_columns.scss" />


## Lism Component

### Import

<ImportPackage component="Columns" />

### Props

| Prop | Description | Default |
|---|---|---|
| `cols` <PropBadge type="cssvar">`--cols`</PropBadge> | Specifies the number of columns. Breakpoint-based values are also supported. | `2` |


## Usage

### 2-column layout

<Preview>
  <PreviewTitle>
    2-column `<Columns>`
  </PreviewTitle>
  <PreviewArea resize p="20">
    <Columns cols={2} g="20">
      <Box bgc="base-2" p="20">Box</Box>
      <Box bgc="base-2" p="20">Box</Box>
      <Box bgc="base-2" p="20">Box</Box>
      <Box bgc="base-2" p="20">Box</Box>
    </Columns>
  </PreviewArea>
  <PreviewCode slot="tab" label="JSX">
    ```jsx "cols={2}"
    <Columns cols={2} g="20">
      <Box bgc="base-2" p="20">Box</Box>
      <Box bgc="base-2" p="20">Box</Box>
      <Box bgc="base-2" p="20">Box</Box>
      <Box bgc="base-2" p="20">Box</Box>
    </Columns>
    ```
  </PreviewCode>
  <PreviewCode slot="tab" label="HTML">
