`a--icon` is a class for displaying icon elements.

## Lism Component

`<Icon>` automatically adds `aria-label` and `role="img"` when `label` is specified, or `aria-hidden="true"` when it is not.

### Import

<ImportPackage component="Icon" />

### HTML Structure

The actual tag rendered varies between `svg`, `img`, and others depending on how `icon`, `viewBox`, `src`, and `as` are specified, but the rules for adding `aria-hidden`/`aria-label` are the same across all of them.

```pug
svg.a--icon[aria-hidden="true"]

or

svg.a--icon[aria-label="..."][role="img"]
```

### Props

| Prop | Description |
|---|---|
| `icon` | An icon component, an SVG string, or an object in the form `{as, ...exProps}`. |
| `size` | Default SVG width and height. Explicit `width` and `height` take precedence. |
| `label` | Output as `aria-label`. When specified, `role="img"` is also added; when omitted, `aria-hidden="true"` is output instead. |


## Usage


### Using `@lism-css/icons`

`@lism-css/icons` is a collection of SVG icons for React and Astro from the creators of Lism CSS. Since `lism-css` itself does not include icon SVG data, install the package separately and pass the components you need to `icon`.

See the [`@lism-css/icons` page](/en/docs/packages/icons/) for installation instructions and the [icon list](/en/docs/packages/icons/#icon-list).

Import from `@lism-css/icons/react` for React or `@lism-css/icons/astro` for Astro.

Use `c` to set the color. See [the `@lism-css/icons` guide](/en/docs/packages/icons/#stroke-width) for stroke width and `weight` options.

#### Combining `as` and `exProps` into `icon`

:::info
In `<Icon>`, you can also pass `as` and `exProps` together in the following format:

```jsx
<Icon icon={{as:Component, exProps1, exProps2, ...}} />
```
:::

You can use icons from third-party packages such as `react-icons` and `@phosphor-icons/react` through `icon` or `as` in the same way. To use React icons in Astro, enable the React integration in Astro.


### Passing an SVG string

You can pass a complete SVG string starting with `<svg` to `icon`, including attributes such as `viewBox` and stroke width.

```jsx
<Icon icon={'<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5"><path d="m5 12 4 4L19 6" /></svg>'} c="green" />
```

### Writing SVG directly

`<Icon>` is rendered as `<svg>` when a `viewBox` prop is specified.
You can place `path` elements and other SVG content directly as children.
