export const PropTable = ({data={}, ...props}) => {
  const dataKyes = Object.keys(data);
  return (
    <Lism as="table" {...props}>
      {/* <thead className="-ta:left">
        <tr>
          <th>Class</th>
          <th>Value</th>
        </tr>
      </thead> */}
      <tbody>
      {dataKyes.map((_propName) => {
        const utils = data[_propName];
        const utilsKeys = Object.keys(utils);
        return (
          <>
            {utilsKeys.map((utilKey) => {
              return (
                <tr>
                  <td><code>{`-${_propName}:${utilKey}`}</code></td>
                  <td><code>{`${utils[utilKey]}`}</code></td>
                </tr>
              );
            })}
          </>
        )
      })}
      </tbody>
    </Lism>
  );

}


Lism provides classes for the most common CSS properties, letting you apply frequently used values and tokens with a single class.<br />
For the most critical properties, responsive breakpoint variants are available too.

These are called **Property Classes** and are defined in the format `-{prop}(:{value})` and `-{prop}_{bp}`.

<PreviewTitle>Examples</PreviewTitle>

```css
.-fz\:l { font-size: var(--fz--l) }
.-fz\:xl { font-size: var(--fz--xl) }
.-ta\:center { text-align: center }
.-d\:none { display: none }
.-p\:20 { --p: var(--s20) }

.-d{display:var(--d)}
.-p,[class*="-p:"]{padding:var(--p)}
@container (min-width: 480px) {
  .-d_sm{display:var(--d_sm)}
  .-p_sm{padding:var(--p);--p:var(--p_sm)!important}
}
@container (min-width: 800px) {
  .-d_md{display:var(--d_md)}
  .-p_md{padding:var(--p);--p:var(--p_md)!important}
}
```


This page lists all available Property Classes.


:::info
You can change which classes are output by [customizing via SCSS](/en/docs/customize/scss/).
:::

## Reading the Tables

Each table covers one group of properties.

| Column | Description |
|---|---|
|**Shorthand**| The abbreviated form of the CSS property. This is the `{prop}` string in the `-{prop}:{val}` class format, and also the prop name used with Lism components.|
|**Property**| The corresponding CSS property |
|**To Class**| Values that are output as Property Classes |
|**BP**| Breakpoint support classes (`-{prop}_{bp}`). `✔` covers `sm`, `md`, and `lg`, and `-` means unsupported. |

The shorthand string itself is what gets output as the class name.

:::info
`current` is shorthand for `currentColor` (the element's text color).

`keycolor` outputs a class that references the `--keycolor` variable (e.g. `.-c\:keycolor { --c: var(--keycolor) }`).

In [`full.css`](/en/docs/css-files/#using-the-full-build-fullcss), every semantic and palette color token is also output as a class (such as `-bgc:red`), in addition to the values listed above.
:::
