**Trait Classes** declare a role on an element or attach a feature to it.  
They belong to `@layer lism-trait`.

- `is--{name}`: declares a **role / existence** (“is a …”).
- `has--{name}`: attaches a **feature** (“has a …”).


## `is--*` (Role declaration)

| Class | Description |
|---|---|
| <ModLink slug="is--container" /> | Defines the reference element for container queries |
| <ModLink slug="is--wrapper" /> | Wrapper element that controls content width |
| <ModLink slug="is--layer" /> | Overlay layer positioned over a parent element |
| <ModLink slug="is--boxLink" /> | Makes the entire box a clickable link |
| `is--coverLink` | A link with a clickable area covering the entire parent element (→ see <ModLink slug="is--boxLink" />) |
| `is--side` | For the side element of `l--withSide` (→ see <ModLink slug="l--withSide" />) |
| `is--skipFlow` | Cancels spacing with the next sibling inside `l--flow` (→ see <ModLink slug="l--flow" />) |


## `has--*` (Feature attachment)


### `has--transition`

Sets the `transition` property using dedicated variables.

<SrcCode path="src/scss/trait/has/_transition.scss" />

By default, the transitioned properties (`--transitionProps`) are limited to colors, shadows, opacity, transform-related, and filter-related properties. Using `all` tends to cause unintended animations (flickering) on page load or layout changes.

We recommend explicitly listing only the properties that actually change via `--transitionProps`. In Lism components, passing a string to `hasTransition` outputs it as `--transitionProps`.

### `has--gutter`

Adds predefined space to the left and right of content. It is kept separate from the padding utilities so you can reserve a uniform amount of space on both sides across the entire site.

| Class name | Spacing | Default value |
|---|---|---|
| `has--gutter` | `--gutter` (baseline: `--gutter--base`) | `var(--s30)` |

### `has--snap`

Lets you configure `scroll-snap` properties via CSS variables.

<SrcCode path="src/scss/trait/has/_snap.scss" />

| Variable | Purpose | Default |
|---|---|---|
| `--snapType` | Value for `scroll-snap-type` | `both mandatory` |
| `--snapAlign` | Value for child `scroll-snap-align` | `start` |
| `--snapStop` | Value for child `scroll-snap-stop` | `normal` |

### `has--mask`

Applies a CSS mask to the element, driven by the `--maskImg` variable.

<SrcCode path="src/scss/trait/has/_mask.scss" />

| Variable | Purpose | Default |
|---|---|---|
| `--maskImg` | Mask image (SVG, etc.) | — |
| `--maskPos` | Mask position | `50%` |
| `--maskSize` | Mask size | `contain` |
| `--maskRepeat` | Mask repeat | `no-repeat` |
