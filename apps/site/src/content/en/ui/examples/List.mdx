An example of a decorative list that displays an icon at the start of each item. It is built with Lism primitives and a small amount of CSS (`b--list`).

The icon is drawn with a pseudo-element's `mask`, so you can swap its color or image using only CSS variables.

## Markup

The markup consists of the following classes and variables.

| Class / Variable | Description |
|---|---|
| `b--list` | Root element. Applied to `<ul>` / `<ol>`. |
| `b--list--check` | Modifier that switches the icon to a check mark. |
| `--icon-c` | Icon color (defaults to `var(--brand)`). |
| `--icon-img` | The image displayed as the icon (a `url()` passed to `mask`). |
| `--icon-size` | Icon size (defaults to `1em`). |
| `--li-ps` | Space reserved at the start of each `li` (defaults to `1.875em`). |

Since the spacing is reserved via `padding-inline-start` on the `li` itself, you can apply border-related Property Classes (such as `-bd-be`) directly to the `li`.
