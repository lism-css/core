An example of a general-purpose table UI that also supports sticky display for the first row and column. It is built with Lism primitives and a small amount of CSS (`b--table`).

The border styles are exposed as CSS variables, so the table also works well with sticky display while scrolling.

## Markup

The markup consists of the following classes and attributes. Adjust the appearance using CSS variables.

| Class / Attribute | Description |
|---|---|
| `b--table` | Root element. Applied to `<table>`. |
| `data-table-sticky` | Sticky display while scrolling. Specify `col` (first-column cells) and/or `head` (`thead`), space-separated. |
| `_nofix` | Add this to cells you want to exclude from sticky display when using `data-table-sticky="col"` — for example, due to `rowspan`. |
| `--bdw-x` / `--bdw-y` | Cell border width (horizontal / vertical). Defaults to `1px`. |
| `--bds` / `--bdc` | Cell border style / color. Defaults to `solid` / `var(--divider)`. |
| `--th-bgc` / `--th-c` | Background color / text color of `th`. |
| `--cells-min-sz` | Minimum cell width (`min-inline-size`). Set this when you want horizontal scrolling. |
| `--cells-p` | Cell padding (`padding` of `td` / `th`). |

Override the CSS variables via the `style` attribute (e.g., `style="--th-bgc:var(--base-2)"`).

### Sticky display while scrolling

The `data-table-sticky` attribute accepts the following values:

- `col`: Sticks the first column of cells
- `head`: Sticks the `thead`
