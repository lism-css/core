## Usage

Provided as `Alert` from the `@lism-css/ui` package.


### Import
<ImportPackage component="Alert" packageName="@lism-css/ui" css="style.css" />


### Props

| Prop | Description |
|---|---|
|`type`| Specifies a preset value combining `keycolor` and `icon`. Default: `"alert"` |
|`icon`| Specifies the icon to pass to the `Icon` component. Pass an icon component or an SVG string. Default icons are bundled with `@lism-css/ui`. |
|`keycolor`| Specifies the key color. |
|`flow`| Passed to the `flow` prop of the `Flow` element that wraps the content. Default: `"s"` |
|`layout`| Switches the layout primitive. Default: `"flex"` |
{/* | `iconProps` | Specifies props to pass to the icon (`<Icon>`). | */}
{/* - `variant`: `'fill'` | `'outline'` ? */}
