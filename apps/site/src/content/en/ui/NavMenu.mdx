### Import

<ImportPackage component="NavMenu" packageName="@lism-css/ui" css="style.css" />


### Props

| Prop | Description |
|---|---|
| <PropBadge>`<NavMenu.Root>`</PropBadge><br/>`hovBgc` | Outputs `--hov-bgc`. (For use when `-hov:-bgc` is applied to `b--navMenu_link`.) |
| <PropBadge>`<NavMenu.Root>`</PropBadge><br/>`hovC` | Outputs `--hov-c`. (For use when `-hov:-c` is applied to `b--navMenu_link`.) |
| <PropBadge>`<NavMenu.Root>`</PropBadge><br/>`itemP` | Outputs the `--item-p` variable. Adjusts the padding of each link at once. |
| <PropBadge>`<NavMenu.Link>`</PropBadge><br/>`hov` | Specifies the hover style. Defaults to `-bgc`, changing the background color on hover. |


## Examples

### Setting common styles for all items at once

Some props can be specified on `NavMenu.Root` and applied to all links at once, instead of setting them directly on each `NavMenu.Link`.

- `itemP` adjusts the padding (`--item-p`) of each `NavMenu.Link`.
- `hovBgc` provides the hover background color (`--hov-bgc`). (Requires `-hov:-bgc` on `NavMenu.Link`.)
- `hovC` provides the hover text color (`--hov-c`). (Requires `-hov:-c` on `NavMenu.Link`.)


To change the padding per breakpoint, set `p` on each `<NavMenu.Link>` instead of using `itemP`.
