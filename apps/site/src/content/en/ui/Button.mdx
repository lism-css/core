## Usage

Provided as `Button` (`b--button`) from the `@lism-css/ui` package.


### Import

<ImportPackage component="Button" packageName="@lism-css/ui" css="style.css" />


### Props

| Prop | Description |
|---|---|
|`variant`| Outputs the `b--button--{variant}` class. Two styles are available by default: the filled (fill) style used when `variant` is not specified, and `outline`. Specifying `fill` adds the `b--button--fill` class, but it has no dedicated styles, so it looks the same as when `variant` is omitted. |
{/* |`layout`| Specifies the layout component that makes up the Button. Defaults to `Lism`. | */}
{/* |`icon`, `endIcon` | Specifies icons to display on either side of the button text. | */}
{/* |`hover`| Defaults to `op`. | */}

## Opt-in Styles

### `hov="reverse"`

An example of adding a [`-hov` class](/en/docs/property-class/hov) that swaps the fill and outline styles on hover.

<Preview css={`
.-hov\\:reverse {
  --hov-c: var(--bgc);
  --hov-bgc: var(--c);
}
.-hov\\:reverse:where(.b--button--fill) {
  --bdc: var(--bgc);
  --hov-bgc: transparent;
}
.-hov\\:reverse:where(.b--button--outline) {
  --hov-c: var(--base);
}
@media (any-hover: hover) {
  .-hov\\:reverse:hover {
    background-color: var(--hov-bgc) !important;
    color: var(--hov-c) !important;
  }
}`}>
  <PreviewTitle>Example</PreviewTitle>

        <Fragment>Button</Fragment>
      </Button>

        <Fragment>Button</Fragment>
      </Button>
    </Flex>
  </PreviewArea>

  <PreviewCode slot="tab" label="Additional CSS">
