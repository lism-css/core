## Base styles

In addition to the Reset CSS, the `lism-base` layer defines default base styles for HTML elements, making use of tokens defined on `:root`.


<PreviewTitle>Source code</PreviewTitle>
<SrcCode path="src/scss/base/_html.scss" />


The styles are presented below, grouped by element type.

:::info
For details on the token variables (`--{prop}--{token}`) used in each style, refer to the [Design Tokens](/en/docs/tokens/) page.
:::


### body

Basic settings for font, color, and text decoration are applied to `body`.

```scss
body {
  --hl: var(--hl--base);
  font-size: var(--fz--base);
  font-family: var(--ff--base);
  letter-spacing: var(--lts--base);
  background-color: var(--base);
  color: var(--text);
  text-underline-offset: 0.125em;
  tab-size: 4;
}
```

`--hl` is a variable that manages the half-leading (the spacing on each side, above and below, of a line). On `body`, `--hl--base` is set and inherited by child elements.

`text-underline-offset` adjusts the position of link underlines, and `tab-size` sets the display width of tab characters.


### Line height for all elements

In Lism CSS, the following style is applied to **all elements**.

```scss
* {
  line-height: var(--lh, calc(1em + var(--hl) * 2));
}
```

Unlike a typical declaration such as `line-height: 1.6`, this approach produces a **fixed line spacing that does not depend on font size**.
The formula works by defining the half-leading amount first, then adding it above and below the character height (approximately `1em`). When `--lh` is set, it takes precedence.

Because line spacing doesn't grow with font size, it unifies the "**vertical rhythm**" of your typography, letting you compose layouts with harmonious spacing from headings down to body text.

For more details, see [Half-Leading (line-height)](/en/docs/half-leading/).


### Headings (h1–h6)

Font family, weight, and size are set for heading elements.

```scss
:is(h1, h2, h3, h4, h5, h6) {
  font-family: var(--headings-ff, inherit);
  font-weight: var(--headings-fw, var(--fw--bold));
}
h1 { font-size: var(--fz--3xl); }
h2 { font-size: var(--fz--2xl); }
h3 { font-size: var(--fz--xl); }
h4 { font-size: var(--fz--l); }
h5, h6 { font-size: var(--fz--m); }
```

By defining `--headings-ff` and `--headings-fw`, you can customize the font family and weight for all headings at once.


### Links (a)

CSS variables for link color and underline are set on the `a` tag.

```scss
a {
  color: var(--link-c, var(--link));
  text-decoration: var(--link-td, underline);
}
```

| Variable | Fallback | Purpose |
|------|------------|------|
| `--link-c` | `var(--link)` | Link text color |
| `--link-td` | `underline` | Text decoration type |

### Inline text elements

```scss
small {
  --hl: var(--hl--s);
  font-size: var(--fz--xs);
}
b, strong {
  font-weight: var(--fw--bold);
}
sup, sub {
  --hl: var(--hl--xs);
  font-size: 80%;
}
code, kbd, var, samp {
  font-family: var(--ff--mono);
  letter-spacing: normal;
}
```

For `small` and `sup`/`sub`, `--hl` is set to a smaller value to adjust the line spacing to match the font size.


### Blockquote

```scss
q, blockquote {
  font-style: italic;
}
blockquote {
  background-color: var(--base-2);
  padding: var(--s20);
}
```

`q` and `blockquote` are displayed in italic, and `blockquote` also gets a simple background color and padding.

### Other text elements

```scss
caption, figcaption {
  font-size: var(--fz--s);
}
```

The font size of these elements is set slightly smaller by default.

### Divider

```scss
hr {
  border: none;
  block-size: 0;
  border-block-start: 1px solid var(--divider);
}
```

`hr` uses a fixed `block-start` direction and is set to the `--divider` color.


### Lists (ul, ol)

```scss
:is(ul, ol):where(:not([class])) {
  list-style: revert;
  padding-inline-start: var(--list-ps, 1.75em);
}
```

While the Reset CSS strips list styles from elements that have a class, this rule automatically restores the browser's default styles for lists with no class at all.

A `ul` / `ol` decorated only with Property Classes (e.g. `<ul class="-fz:l">`) remains in the reset state. If you want to keep the list markers in that case, add [`set--revert`](/en/docs/set-class#set--revert) explicitly.

```html
<ul class="-fz:l set--revert">
  <li>item 1</li>
  <li>item 2</li>
</ul>
```

| Variable | Fallback | Purpose |
|------|------------|------|
| `--list-ps` | `1.75em` | List `padding-inline-start` |


### Definition lists (dl)

```scss
dt {
  font-weight: var(--fw--bold);
}
dd + dt {
  margin-block-start: var(--s20);
}
```

`dt` is displayed in bold, and spacing is added between consecutive `dd + dt` pairs to clearly separate entries.


### Tables

The padding of `td` and `th` can be customized via `--cells-p`.

```scss
td, th {
  padding: var(--cells-p, 0.625em 0.875em);
}
```

| Variable | Fallback | Purpose |
|------|------------|------|
| `--cells-p` | `0.625em 0.875em` | Cell padding |


### Form elements

Consistent styles are applied to form controls.

```scss
input:where(:not([type='range'])), button, textarea, select, ::file-selector-button {
  background-color: var(--controls-bgc, var(--base-2));
  border: solid 1px var(--controls-bdc, var(--divider));
  padding: var(--controls-p, 0.25em 0.5em);
}
```

| Variable | Fallback | Purpose |
|------|------------|------|
| `--controls-bgc` | `var(--base-2)` | Background color |
| `--controls-bdc` | `var(--divider)` | Border color |
| `--controls-p` | `0.25em 0.5em` | Padding |

Border radius is left to the browser's default styles. If you want a consistent rounding, apply `border-radius` directly to each selector in your theme.


### Others

```scss
:disabled {
  opacity: var(--o--pp);
}
:focus-visible {
  outline-offset: var(--focus-offset, 0px);
}
```

Disabled elements have reduced opacity, and `:focus-visible` allows the outline offset to be adjusted with `--focus-offset`.
