1行目・1列目の固定表示にも対応した、汎用的なテーブル UI の実装例です。Lism の primitives と少量の CSS（`b--table`）で構成します。

ボーダーのスタイルをCSS変数で調整できるようにしておくことで、スクロール時の固定表示にも対応できるように設計しています。

## Markup

マークアップは以下のクラス・属性で構成します。見た目の調整はCSS変数で行います。

| クラス / 属性 | 説明 |
|---|---|
| `b--table` | ルート要素。`<table>` に付与します。 |
| `data-table-sticky` | スクロール時の固定表示。`col`（1列目のセル）・`head`（`thead`）をスペース区切りで指定します。 |
| `_nofix` | `data-table-sticky="col"` の使用時、`rowspan` の都合などで固定表示から除外したいセルに付与します。 |
| `--bdw-x` / `--bdw-y` | セルのボーダー幅（左右 / 上下）。デフォルトは `1px` です。 |
| `--bds` / `--bdc` | セルのボーダーのスタイル・色。デフォルトは `solid` / `var(--divider)` です。 |
| `--th-bgc` / `--th-c` | `th` の背景色・文字色。 |
| `--cells-min-sz` | セルの最小幅（`min-inline-size`）。横スクロールさせたい場合に指定します。 |
| `--cells-p` | セルの余白（`td` / `th` の `padding`）。 |

CSS変数は `style` 属性で上書きします（例: `style="--th-bgc:var(--base-2)"`）。
