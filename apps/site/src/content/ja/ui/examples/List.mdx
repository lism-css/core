行頭にアイコンを表示する装飾リストの実装例です。Lism の primitives と少量の CSS（`b--list`）で構成します。

アイコンは疑似要素の `mask` で描画しているため、色や画像をCSS変数だけで差し替えられます。

## Markup

マークアップは以下のクラス・変数で構成します。

| クラス / 変数 | 説明 |
|---|---|
| `b--list` | ルート要素。`<ul>` / `<ol>` に付与します。 |
| `b--list--check` | チェックマークのアイコンに切り替えるモディファイア。 |
| `--icon-c` | アイコンの色（デフォルトは `var(--brand)`）。 |
| `--icon-img` | アイコンとして表示する画像（`mask` に渡す `url()`）。 |
| `--icon-size` | アイコンのサイズ（デフォルトは `1em`）。 |
| `--li-ps` | `li` の行頭に確保する余白（デフォルトは `1.875em`）。 |

余白は `li` 側の `padding-inline-start` で確保しているため、`li` にボーダー系の Property Class（`-bd-be` など）をそのまま付与できます。
