## How to use

`@lism-css/ui` パッケージで`Button`(`b--button`)として提供しています。


### Import

<ImportPackage component="Button" packageName="@lism-css/ui" css="style.css" />


### Props

| プロパティ | 説明 |
|---|---|
|`variant`| `b--button--{variant}` クラスを出力します。標準で用意しているスタイルは、`variant`を指定しない時の塗りつぶし（fill）スタイルと、`outline`の2種類です。`fill`を指定すると`b--button--fill`クラスが付きますが、専用のスタイルはなく、指定しない時と見た目は変わりません。|
{/* |`layout`| Buttonを構成するレイアウト用コンポーネントを指定できます。デフォルトは`Lism`です。| */}
{/* |`icon`, `endIcon` | ボタンテキストの左右に表示するアイコンを指定できます。| */}
{/* |`hover`| デフォルトは`op`が指定されています。| */}

### `Grid`でアイコンを端に寄せる

## Opt-in Styles

### `hov="reverse"`

ホバー時に、fill,outlineが入れ替わるような [`-hov`クラス](/docs/property-class/hov)を追加する例を紹介します。

<Preview css={`
.-hov\\:reverse {
  --hov-c: var(--bgc);
  --hov-bgc: var(--c);
}
.-hov\\:reverse:where(.b--button--fill) {
  --bdc: var(--bgc);
  --hov-bgc: transparent;
}
.-hov\\:reverse:where(.b--button--outline) {
  --hov-c: var(--base);
}
@media (any-hover: hover) {
  .-hov\\:reverse:hover {
    background-color: var(--hov-bgc) !important;
    color: var(--hov-c) !important;
  }
}`}>
