## lism-css v0.31.0 (2026.09.30)

**破壊的変更**を含むリリースです。

- **破壊的変更:** 後方互換のために宣言だけ残していた`lism-component`レイヤーを削除しました。`@layer lism-component`に書いたCSSは優先度が変わるため、`lism-block`または`lism-custom`へ移してください（#645）。
  - `@lism-css/ui` v0.26.0未満を使っている場合は、v0.26.0以上へ更新してください。
  - v0.26.0より前に`lism-cli ui add`で追加したコンポーネントは、`_style.css`の`@layer lism-component`を`lism-block`へ書き換えてください。
- **破壊的変更:** 非推奨だったコンポーネントエイリアス`SideMain` / `FluidCols` / `SwitchCols`と`Dummy`コンポーネントを、`lism-css/react`と`lism-css/astro`から削除しました。それぞれ`WithSide` / `AutoColumns` / `SwitchColumns`と`@lism-css/ui`の`DummyText`へ移行してください（#646）。
- **破壊的変更:** Lism Propsの変換設定をprop単位で上書きする`_propConfig`を、`getLismProps`と各コンポーネントのpropsから削除しました。変換設定を変えたい場合は、[`lism.config.js`の`props`](/docs/customize/config/)で設定してください（#225）。

### `@lism-css/ui` v0.31.0 (2026.09.30)

- コンポーネントのCSSが`lism-css/main.css`より前に出力されると、`lism-base`のスタイルが`b--*`のスタイルより優先される不具合を修正しました（`a`要素の`Button`に下線とリンク色が残るなど）。各コンポーネントのCSSと`style.css`の先頭で、`lism-base`と`lism-block`の順序を宣言します（#644）。
- Astro版の`Tabs` / `Accordion` / `Modal`が、`ClientRouter`で遷移した先のページで動作しない不具合を修正しました。読み込み時に加えて`astro:page-load`でも初期化し、同じ要素にはイベントを重ねて登録しません（#640）。

## lism-css v0.30.0 (2026.09.22)

- 公開パッケージの`.d.ts`が`config`を相対パスでimportしていたため、利用側でpropsの型が`any`に落ちる不具合を修正しました（#494, #639）。
- Astroの`Box` / `Layer` / `BoxLink` / `Decorator` / `Spacer` / `Divider`で、`exProps`に指定したプロパティがLism Propsとして処理されていた問題を修正しました。他のコンポーネントやReact版と同じく、`exProps`はLism Propsの処理をスキップしてそのまま属性に渡されます（#636）。
- 公開物からテスト・stories等の内部ファイルを除外しました。`lism-css/base/set.css`の単体出力は廃止しました（`base.css` / `main.css`には引き続き含まれます）（#637）。

### `@lism-css/plugin` v0.5.1 (2026.09.22)

- Astro 7とVite 8（Rolldown）に対応しました（`peerDependencies`を`astro: ^6 || ^7`、`vite: ^6 || ^7 || ^8`へ拡張）（#630）。
- CSS Purgeで`client:only`のislandや、HTMLにLismクラスが無いままクライアントJSにLismランタイムが含まれる構成（CSRの可能性）を検出したとき、スタイル欠落の可能性を警告するようにしました。実行時にpropsから生成されるクラスは検出できないため、`safelist`で残すかpurgeを無効にしてください（#634）。

### `@lism-css/ui` v0.30.0 (2026.09.22)

**破壊的変更**を含むリリースです。

**Tabs (#87, #642)**

- **破壊的変更:** `Tabs.Tab`は`button`固定になり、`as`によるタグ変更を受け付けなくなりました。
- React版で`Tabs.Item`を使わず`Tabs.List` / `Tabs.Tab` / `Tabs.Panel`を直接組み合わせる手動構成に対応しました。
- React版で、選択中の`Tabs.Tab`がDOMから取り除かれた場合に、残っている先頭のタブへ選択（とフォーカス）を移すようにしました。

## lism-css v0.29.0 (2026.09.13)

**破壊的変更**を含むリリースです。

### Iconとアイコンパッケージ (#616, #618, #619)

- **破壊的変更:** `Icon`の名前指定プリセットとコアのSVGデータを廃止しました。`@lism-css/icons/react`または`@lism-css/icons/astro`から必要なコンポーネントをimportし、`icon={Check}`のように指定してください。
- `Icon`は`weight`（light 1 / regular 1.5 / bold 2）と`strokeWidth`に対応します。`@lism-css/icons`の線アイコンは24グリッド・既定の線幅1.5で描画され、色は`c`で指定できます。従来の太字caret・arrowは`weight="bold"`で再現できます。`dot`は廃止しました。
- アイコンは全てオリジナル設計の`@lism-css/icons`として、別リポジトリ[lism-css/icons](https://github.com/lism-css/icons)から公開します。収録アイコンは[`@lism-css/icons`のページ](/docs/packages/icons/)を参照してください。

### その他

- `sz` / `min-sz` / `max-sz`をブレイクポイント対応（`bp: 1`）にしました。`w`系と同じく`-{prop}_{bp}`クラスで画面幅ごとに値を切り替えられます。`-max-sz:full` / `-max-sz:bleed`はブレイクポイント値としては使えません。単一値指定の出力は`style`属性への直書きから`-sz`クラス＋`--sz`変数のセットへ変わります（`max-sz`のトークン値と`full` / `bleed`は従来どおりクラス出力）（#613）。
- **破壊的変更:** `lh`トークンを`xs: 1.125` / `s: 1.25` / `m: 1.5` / `l: 1.75` / `xl: 2`へ変更しました（旧: `1.25` / `1.5` / `1.75` / `2` / `2.25`）。`m`を`1.5`に据えた0.25刻みのスケールになります（#614）。
- **破壊的変更:** `text-transform`のクラス名を`-tt:upper` / `-tt:lower`から`-tt:uppercase` / `-tt:lowercase`へ変更しました。propsの`tt="upper"` / `tt="lower"`は互換として維持し、新しいクラスへ解決します（#615）。

### `@lism-css/plugin` v0.5.0 (2026.09.13)

**破壊的変更**を含むリリースです。

- `lism-css`を`dependencies`から`peerDependencies`（`*`）へ移し、利用側にインストールされている`lism-css`からCSSを生成するようにしました。pluginが`lism-css`を同梱しなくなるため、`lism-css`は利用側で導入してください（#609）。

### `@lism-css/ui` v0.29.0 (2026.09.13)

- Alert・Calloutの既定アイコンとModal・Popoverの閉じるアイコンのSVGデータを同梱しました。既定アイコンの利用に追加importは不要です。
- `Button`の`fill`（既定）のボーダー色`--bdc`を`var(--bgc)`から`transparent`へ変更しました。`hov="-bgc"`などで背景色だけを変えたときに、ボーダーが元の色で縁として残らなくなります。ホバー時に枠線を残したい場合は`--bdc: var(--bgc)`を指定してください（`hov="reverse"`の例を参照）。

## lism-css v0.28.0 (2026.09.05)

**破壊的変更を含みます。**

- 余白トークン`--s45`を追加し、`--s80`を削除しました。`s="80"`は`s="70"`または任意の値へ置き換えてください。
- `u--divide` / `u--enclose`をコアと`util`のプリセット型から削除しました。引き続き使う場合は、[Utility Class](/docs/utility-class/)のOpt-in節にあるCSSを追加してください（#603）。
- `lts`の`xs`〜`xl`を`--lts--base`からの相対値にし、基準値を`normal`から`0em`へ変更しました。基準値の上書きは`:root`で長さを指定してください。
- ホバー時の変形用に`-hov:-transform`を追加しました（#605）。
- opacityトークンの`p` / `pp` / `ppp`を`0.8` / `0.6` / `0.4`へ変更しました。

**`@lism-css/plugin` v0.4.4 (2026.09.05)**

- `lism-css` v0.28.0に追従しました。コードの変更はありません。

**`@lism-css/ui` v0.28.0 (2026.09.05)**

**破壊的変更を含みます。** `lism-css` v0.28.0以上が必要です。

- UI・実装例の子要素用CSS変数を改名しました（`--_item-p` → `--item-p`など）。`--_gap`は`--popup-gap`、`--_panel-h` / `--_content-gtr`は`--_panelH` / `--_contentGtr`へ変更しました（#607）。
- 旧変数名は使えません。コピー済みのCSS・ソースと、独自の変数指定・参照をまとめて更新してください。Props名は変わりません。
- `lism-css`の同梱をやめ、外部依存へ変更しました。`lism.config`のトークン変更がUIの再ビルドなしで反映されます（#604）。
- Accordionのボタンの既定`gap`を`--s10`から`--s15`へ変更しました。

## lism-css v0.27.0 (2026.09.04)

**破壊的変更を含みます。**

- `lh`を単位なしの比率で`line-height`を指定するpropへ変更しました。従来の行間調整に使っていた`lh="s"`などは`hl="s"`へ置き換えてください。`lh="1"`の動作は変わりません（#583）。
- `--s-unit` / `--hl-unit`を`0.5rem` / `0.125rem`へ固定し、`--fz--base`との連動をやめました。余白をフォントサイズに連動させる方法は[Tokens](/docs/tokens/)を参照してください（#581）。
- `bdrs`のスケールを変更し、`50`を追加しました。`20`〜`40`は従来より小さくなります（#579）。
- `has--transition`の既定の対象を`all`から色・影・変形などに限定しました。`hasTransition="color, opacity"`のような直接指定にも対応しました（#584）。
- `no_layer`ビルドでProperty Classを`!important`化し、Utility Classのセレクタを二重化しました（#585）。
- `u--trim` / `u--trimAll`を`hl`・`lh`の両方に対応させました（#583）。
- `hl`に`xl`、`lts`に`xs`トークンを追加しました。
- `bxsh`を2層の影へ変更し、影色を調整しました（#591）。`set--bdrsInner`の計算値にも`+1px`の補正を加えました（#579）。
- `-bd`が上位レイヤーの`border`に上書きされる問題と、`Center`内の長い`pre`による横幅超過を修正しました（#589, #597）。
- `-hov:-bgc`の既定の混色率を25%から20%へ変更しました。

**`@lism-css/ui` v0.27.0 (2026.09.04)**

`lism-css` v0.27.0以上が必要です。

- Tooltip / Popoverを追加しました（#588）。
- Avatarで`src`未指定時に`name`の先頭1文字を表示するようにしました（#587）。
- Modal内のページ内リンクを通常クリックすると、モーダルを閉じるようにしました（#596）。

## lism-css v0.26.0 (2026.08.16)

- `lism-base`の直後に`lism-block`レイヤーを追加しました。旧`lism-component`の宣言は互換性のため残しています（#546, #559）。
- 独自クラスを`b--`（Block Class）と`c--`（Custom Class）に整理し、`p--` / `z--`の規約を廃止しました（#546）。
- 依存パッケージのセキュリティ更新を行いました。

**`@lism-css/ui` v0.26.0 (2026.08.16)**

**破壊的変更を含みます。** `lism-css` v0.26.0以上が必要です。

- クラス名を`c--{name}`から`b--{name}`へ変更しました。上書きCSSは`lism-component`から`lism-block`または`lism-custom`へ移してください（#559）。
- ベーススタイルの一部をPropsからCSSへ移しました。Badgeの角丸をピル型に変更し、Avatarの既定サイズはCSSの`--w: 2em`で管理します（#559）。
- Tabsの`variant="line"`を標準スタイルにし、既定の`variant`を`default`へ変更しました（#559）。
- Button / Accordion.Root / Details / NavMenuの既定の`l--flex` / `l--stack`を廃止しました。必要なら`layout="flex"`などを指定してください（#559）。
- Details.Contentの`flow="s"`を廃止しました。以前の間隔に戻すには`.b--details_content { --flow--base: var(--flow--s) }`を指定してください（#559）。
- Tabsのキーボード操作とReact版の`?lism-tab=`に対応しました。パネルを`aria-hidden`から`hidden`へ変更し、範囲外の`defaultIndex`による不具合も修正しました（#559）。
- Modalのアクセシビリティと開閉処理を改善し、ドラッグ時に誤って閉じる問題や、閉じた後の状態復元を修正しました。`setEvent`の対象は`dialog`要素に限定しました（#563）。
- Chatをパッケージから削除しました。[実装例](/ui/block-examples/chat/)のCSSを`@layer lism-block`ごとコピーしてください（#564）。

- **v0.10.x (2026.04.03〜04.05)**: `<HTML.xxx>` を廃止し、セマンティックラッパーコンポーネント（`Text` / `Inline` / `Group` / `Heading` / `Link` / `List` 等）に置き換え。ネガティブマージンのトークン指定（`mt="-10"` 等）に対応。`@layer` 命名を `lism-xxx` 形式に変更
- **v0.9.x (2026.03.17〜03.31)**: React コンポーネントを TypeScript 化。クラス命名を `--` 区切りに変更（`set-xxx` → `set--xxx`、`u-xxx` → `u--xxx`）。`@lism-css/ui` / `@lism-css/mcp` の公開を開始
- **v0.8.x**: line-height をハーフレディングで管理するシステムに変更。レイアウトモジュールを再編（`WithSide` → `SideMain`、`FluidCols` の独立、`SwitchCols` 追加）。ダイナミックモジュール（accordion / modal / tabs）を削除し `@lism-css/ui` へ移行。トークン名を多数変更（`--c--main` → `--brand`、`--c--line` → `--divider` 等）
