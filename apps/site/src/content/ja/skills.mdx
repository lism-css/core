プロジェクトに SKILL.md ファイルを配置することで、AIエージェントに Lism CSS の設計ルール・Props・トークン・命名規則などを伝えることができます。

配布しているスキルは次の3つです。

| スキル名 | 用途 |
|---|---|
| `lism-css-guide` | 新規実装（デザイン/要件→コード）向けの設計ルール・Props・トークン・命名規則 |
| `lism-css-refactor` | 既存のLism CSSコードを、見た目や挙動を変えずにLism CSSの設計ルールに沿った書き方へ整理するリファクタ用 |
| `lism-mockup-guide` | [`@lism-css/mockup`](https://github.com/lism-css/core/tree/main/packages/mockup)で画面モックアップを組むためのワークフローとデータの受け渡し形式（`lism-css-guide`併用前提） |

GitHub: [core/skills/lism-css-guide/](https://github.com/lism-css/core/tree/main/skills/lism-css-guide) / [core/skills/lism-css-refactor/](https://github.com/lism-css/core/tree/main/skills/lism-css-refactor) / [core/skills/lism-mockup-guide/](https://github.com/lism-css/core/tree/main/skills/lism-mockup-guide)


## セットアップ

[skills.sh](https://skills.sh) を使うと、以下のコマンドで簡単にスキルを取得できます。

### gh コマンド経由

[GitHub CLI](https://cli.github.com/) を使っている場合は、`gh skill install` でも取得できます。

```bash frame="none"
gh skill install lism-css/core lism-css-guide@main
gh skill install lism-css/core lism-css-refactor@main
gh skill install lism-css/core lism-mockup-guide@main
```


### lism-cli 経由

`lism-cli skill add` からも同じスキルを取得できます。プロジェクト直下への配置のみ対応していますが、`skill check` コマンドでGitHub上のスキルとローカルの差分を確認できるのが特徴です。引数なしで実行すると上記3つのスキルすべて（`lism-css-guide` / `lism-css-refactor` / `lism-mockup-guide`）が対象になります。

対話モードでは、プロジェクト直下にある各ツールのディレクトリやファイル（`.claude/`, `.cursor/` 等）を検出し、該当ツールを最初からチェックした状態で候補に表示します。非対話でツールを明示指定する場合は、以下のようなフラグを渡します。

```bash frame="none"
# 単一ツールに配置（スキル名の省略時は3つのスキルすべて）
npx lism-cli skill add --claude

# 複数ツールを同時に
npx lism-cli skill add --claude --cursor

# 全ツール
npx lism-cli skill add --all

# スキル名を指定して個別に配置
npx lism-cli skill add lism-css-refactor --claude
```

#### 配置先の対応表

`lism-css-guide` を例にした配置先です。他のスキルの場合はディレクトリ名だけが置き換わります（例: `.claude/skills/lism-css-refactor`）。

| フラグ | 配置先 |
|--------|--------|
| `--claude` | `.claude/skills/lism-css-guide` |
| `--codex` | `.agents/skills/lism-css-guide` |
| `--cursor` | `.cursor/skills/lism-css-guide` |
| `--windsurf` | `.windsurf/skills/lism-css-guide` |
| `--cline` | `.cline/skills/lism-css-guide` |
| `--copilot` | `.github/skills/lism-css-guide` |
| `--gemini` | `.gemini/skills/lism-css-guide` |
| `--junie` | `.junie/skills/lism-css-guide` |


#### アップデート

GitHub上のスキルとローカルのファイル差分を確認してから更新できます。

```bash frame="none"
# GitHub上のスキルとローカルのファイル差分をチェック（変更 / 追加 / 削除のサマリ表示）
npx lism-cli skill check

# 最新版で上書き
npx lism-cli skill update --claude
```

`skill check` は配置済みの各ファイルを sha256 で比較し、変更 / 追加 / 削除されたファイルをまとめて表示します。最新情報が気になる場合は [GitHub リポジトリ](https://github.com/lism-css/core/tree/main/skills/lism-css-guide) を直接チェックしてください。
