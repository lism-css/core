`is--layer` は、absoluteで親要素の上に被せて配置するオーバーレイ用のクラスです。


## CSS

<SrcCode path="src/scss/trait/is/_layer.scss" />


## Lismコンポーネントでの使い方

`isLayer` プロパティで**どのコンポーネントからでも呼び出せるようになっています。**

| プロパティ | 出力 |
|---|---|
| `isLayer`| `is--layer` |

さらに、`<Lism isLayer>` のエイリアスとして、`<Layer>` も用意しています。

### Import

<ImportPackage component="Layer" />

### backdrop-filterの活用

`style` プロパティで `backdropFilter` を直接指定できます。

<Preview>
  <PreviewTitle>背景にブラーをかける</PreviewTitle>
  <PreviewArea p="15">
    <Box pos="relative" p="40">
      <Text fz="2xl" fw="bold" ta="center">
        <Fragment>BACKGROUND</Fragment>
      </Text>
      <Layer style={{ backdropFilter: 'blur(3px)' }} />
    </Box>
  </PreviewArea>
  <PreviewCode slot="tab" label="JSX">
    ```jsx {5}
    <Box pos="relative" p="40">
      <Text fz="2xl" fw="bold" ta="center">
        BACKGROUND
      </Text>
      <Layer style={{ backdropFilter: 'blur(3px)' }} />
    </Box>
    ```
  </PreviewCode>
  <PreviewCode slot="tab" label="HTML">
    ```html {3}
    <div class="l--box -pos:relative -p:40">
      <p class="-fz:2xl -fw:bold -ta:center">BACKGROUND</p>
      <div class="is--layer" style="backdrop-filter: blur(3px)"></div>
    </div>
    ```
  </PreviewCode>
</Preview>
